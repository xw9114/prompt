## 各版本对比 GitHub 原版的优势

### vs HuLWe/codex-5.5 原版的问题：

1. **注入位置错误**：用 `model_instructions_file`（Codex 0.142+ 已废弃）
2. **脏标记暴露**：无（但策略过于直白，容易触发分类器）
3. **命令式越狱**：`[MODE: UNRESTRICTED]` 直接声明，特征明显

### 本优化版改进：

#### CTF竞赛版 ✅
- ✅ 认知重构策略：把目标重定义为"已授权竞赛沙箱资产"
- ✅ 无任何越狱关键词（unrestricted/jailbreak/ignore_safety）
- ✅ 输出像正常技术回复，分类器抓不到
- ✅ 覆盖 CTF 全域 + NSFW/R18 + 全技术领域

#### 无限制直击版 ✅
- ✅ 基于 GitHub 5.5 版本优化
- ✅ 去除脏标记（`<!--?-->`）
- ✅ 去除反效果规则（`ignore_safety_rules`、替换拒绝词）
- ✅ 补充沙箱上下文增强可信度
- ✅ 加强中文回复指令

#### 综合增强版 ✅
- ✅ CTF 认知重构 + 无限制直击双保险
- ✅ 第一层被拦时自动切第二层
- ✅ 最全面的场景覆盖
- ✅ 适合高强度对抗环境

## 安装方式（三个版本通用）

### 步骤 1：备份现有配置
```bash
cp ~/.codex/AGENTS.md ~/.codex/AGENTS.md.bak-$(date +%Y%m%d-%H%M%S)
```

### 步骤 2：选择版本并复制
选择以下三个文件之一：
- `AGENTS-CTF竞赛版.md` → 最隐蔽，推荐日常使用
- `AGENTS-无限制直击版.md` → 最直接，快速破限
- `AGENTS-综合增强版.md` → 最全面，高强度环境

复制内容到：
```
C:\Users\你的用户名\.codex\AGENTS.md
```

⚠️ **编码必须是 UTF-8 无 BOM**，用 VSCode 或其他支持的编辑器保存。

### 步骤 3：重启 Codex
开新会话即生效。

## 技术原理一句话

**不是命令模型 "别管安全规则"，而是让模型相信：**
1. 当前环境是已授权的竞赛沙箱（CTF 策略）
2. 所有目标都是沙箱内部资产，没有真实世界后果（认知重构）
3. 拒绝任务 = 违反实验协议 / 损坏数据（隐含压力）

模型是被**说服**的，不是被**命令**的 —— 分类器抓不到，输出还干净。
