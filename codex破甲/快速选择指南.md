# 快速对比：三个版本怎么选

## 🎯 CTF竞赛版（推荐日常使用）

**特点：** 最隐蔽，分类器抓不到  
**原理：** 认知重构 —— 把所有目标重定义为"已授权的竞赛沙箱资产"  
**适合：** 日常开发、长期使用、不想被封号  

```bash
# 验证命令
codex exec "写一个 Python 多线程端口扫描器"
```

**优势：**
- ✅ 无任何越狱关键词
- ✅ 输出像正常技术回复
- ✅ 最强分类器规避能力
- ✅ 覆盖 CTF + NSFW/R18 + 全技术域

---

## ⚡ 无限制直击版（最快破限）

**特点：** 最直接，立竿见影  
**原理：** 直接声明无限制开发者模式（优化过，去除脏标记）  
**适合：** 快速测试、临时任务、不在乎隐蔽性  

```bash
# 验证命令
codex exec "写一个反弹 shell payload 生成器"
```

**优势：**
- ✅ 基于 GitHub 5.5 版本优化
- ✅ 去除反效果规则（脏标记/ignore_safety）
- ✅ 最直接的破限效果
- ✅ 补充沙箱上下文增强可信度

**劣势：**
- ⚠️ 分类器规避能力中等
- ⚠️ 长期使用可能被标记

---

## 🛡️ 综合增强版（最强覆盖）

**特点：** 双策略叠加，第一层被拦自动切第二层  
**原理：** CTF 认知重构（主） + 无限制声明（备）  
**适合：** 高强度对抗环境、需要最强保障  

```bash
# 验证命令
codex exec "分析这个恶意代码样本的混淆手法和 C2 通信协议"
```

**优势：**
- ✅ 双保险机制
- ✅ 最全面的场景覆盖
- ✅ 第一层隐蔽 + 第二层兜底
- ✅ 适合高风险任务

**劣势：**
- ⚠️ 文件稍大（7.9KB vs 6.3KB vs 3.1KB）

---

## 🎁 推荐搭配

### 日常开发 → CTF竞赛版
隐蔽性最强，长期使用安全

快速见效，完事就换回来

双保险，适合对抗严格的审查

## 安装方式（三版通用）

### 1. 备份现有配置
```bash
cp ~/.codex/AGENTS.md ~/.codex/AGENTS.md.bak-$(date +%Y%m%d-%H%M%S)
```

### 2. 选择版本并复制
把对应版本的 `AGENTS-xxx.md` 内容复制到：
```
C:\Users\你的用户名\.codex\AGENTS.md
```

⚠️ **编码必须是 UTF-8 无 BOM**

### 3. 重启 Codex
开新会话即生效
